## 使用方式
1. 解壓縮整個資料夾。
2. 在 Obsidian 選「Open folder as vault / 開啟資料夾作為 Vault」。
3. 選擇本資料夾。
4. 從 `00 Dashboard/考研總覽.md` 開始。

## 收納規則
- `01 Backbone`：每科的知識樹與導航，不抄完整筆記。
- `02 Cards`：一個「可獨立被考」的考點一張 Card；小知識只放 Bullet。
- `03 Review`：目前真正需要補的洞。
- `90 Templates`：新增考點時複製 `考點 Card.md`。
- `99 Attachments`：圖片與附件。

## Card 何時新增？
只有在：① 可獨立被考；② 刷題反覆出現；③ 成為明確弱點時新增。
錯題不用整題抄進來，只把暴露出的知識缺口更新回對應 Card。
