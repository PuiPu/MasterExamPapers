# closure
- meaning : 原本沒有滿足性質(reflexive, symmetric, transitive)，透過加入 element 去擴增到滿足性質，而使加入的 elements 個數最少
- type
	- reflexive closure
	- symmetric closure
	- transitive closure
- using `Warshall` algo. to solve transitive `closure` [Floyd-Warshall Algorithm Explained](https://youtu.be/sLg6Leb-xt0?si=60fil269xNT_Ptuo)
