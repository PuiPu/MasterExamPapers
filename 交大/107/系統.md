# memory hierarchy
- 多層 hierarchy
	- 增加 memory capacity
	- 降低 average access time (AMAT)
		- 大多部分都在 cacahe hit
		- 只有少部分在慢速 memory
- cache 使用 cache block/line 來利用 spatial locality (cache line 通常一次抓很多 byte, ex. CPU 要抓 A[0], cache 會順便抓 A[1], A[2], A[3], 因為程式通常會連續存取資料)
- cache 大小是 tradeoff
	- cache 大 $\rightarrow$ miss rate 下降 $\rightarrow$ hit time 會增加(成本更高、功耗更高)
- CPU cache (L1/L2/L3) 通常由 hardware manage，OS 不直接管理 cache line
	- virtual memory / page table 才是 OS 管理
